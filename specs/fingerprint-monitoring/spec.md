# 定期指纹检测与界面重构

状态：已实现；自动验证和用户验收分别记录于 [验收](contracts/acceptance.md)。
来源：2026-11-13 用户确认的实施计划。本规格扩展首期仅 milk 的边界。

## 目标与边界

使用固定 lmfpd-sdk 0.2.0 数字挑战，定期观察参考库中最相近模型及其概率。保持 Bun、SQLite、原生 HTML/CSS/JavaScript；不增加前端构建或运行时 npm 安装。无自动封锁、身份认证、账号固定和云端同步。

## 需求

| ID | 可观察行为 | 失败或边界场景 |
| --- | --- | --- |
| FP-001 | 每模型有 milk 和 fingerprint 两种独立计划；开关、间隔、推理强度、超时分别保存 | 指纹默认暂停、间隔为空，用户填写后才能启用；允许直接手动检测 |
| FP-002 | 每轮最多三条数字挑战，经 Magpie Chat Completions 网关逐条请求，以 SDK 宽松模式评分 | 部分样本保留候选，概率由 SDK 决定，空值展示 —；无可用排名显示原因 |
| FP-003 | 同模型同类型去重，同模型两种检测串行，全局最多两条模型请求 | 无自动重试；手动仅推进本类型计划；暂停不取消当前任务；移除取消两种任务 |
| FP-004 | 超时为整轮期限，默认 300 秒；范围 10–3600 秒；间隔范围 1–43200 分钟 | 超时、取消、重启保留证据，中断不产生最终评分；不积压补跑 |
| FP-005 | 首次指纹运行无缓存时下载；有缓存后服务端每 24 小时更新，可手动更新 | 页面读取不下载；更新合并，校验 SHA-256，原子替换；失败保留缓存并提示，下一日再尝试 |
| FP-006 | 每轮固定参考快照，保存 SDK、构建版本、快照哈希、实际请求、题目、回答、采样与路由证据 | 已知路由不匹配不评分；路由查询不可用明确提示；密钥不进入页面或证据 |
| FP-007 | 保留历史／设置两主 Tab；历史默认奶牛，可切换指纹 | 删除页面大标题和副标题，保留宿主侧栏名；透明 Tab、宿主主题与系统字体 |
| FP-008 | 指纹按服务时区日期分组，倒序时间线每页 20 条；突出候选和一位小数百分比 | 显示来源、耗时、有效样本数；详情 Top 3、完整排名和证据；不支持人工矫正 |
| FP-009 | 相邻完整评分同快照同 SDK 候选不同标记候选变化，跨页比较正确 | 部分评分不触发候选变化；快照变化单独标记；不把参考库更新解读为身份变化 |
| FP-010 | 清空仅针对当前模型、类型的全部终态；移除配置保留历史 | 未完成任务保留；奶牛热力图和人工日志不混入指纹 |
| FP-011 | 数据库 v1 到 v2 事务迁移保留历史、自动与人工证据、旧计划 | 旧数据归 milk；补暂停的指纹配置；旧接口不传 testId 默认 milk；高版本库拒绝打开 |
| FP-013 | 新页面识别旧版后台并阻止配置、运行和历史展示，提示重载插件；恢复后重绘设置 | 不把旧 milk 历史展示为指纹；旧服务不支持的参考库操作不进入等待状态 |
| FP-012 | 375–1440 像素界面可操作，键盘可达、有焦点、支持减少动态效果 | 输出按文本，空态／错误可读；正常连接不显示状态文字 |
| FP-014 | 历史模型选择器及展开列表跟随主题；选项显示名称、完整 ID、已移除状态与选中标记；方向键、Home/End 及 Enter 可切换，Esc／点击外部关闭 | 长 ID 可换行，列表受窗口边界约束并独立滚动；暂无模型时禁用。测试详情和添加模型标题／关闭按钮固定，正文独立滚动；详情、添加及确认弹层打开时锁定主页面滚动，关闭后保留原位置 |
