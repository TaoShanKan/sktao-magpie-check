# 监测界面优化 · 实施方案

## 方案

ui/index.html 负责上下文工具栏、更多菜单、统计及可访问日期筛选。ui/app.js 负责按类型摘要、热力滚动保留、浮层、紧凑计划、证据优先详情和本页分组。ui/style.css 统一语义色和响应式布局。

Store 在摘要查询中使用窗口函数对完整指纹历史标注前一快照及前一完整评分；变化筛选先于 LIMIT/OFFSET。history 增加 changes 查询参数及 previousPrediction、sampleProgress 摘要；fingerprintSummary 给出最近 30×24 小时统计。列表和统计不包含长回答或原始请求。无新依赖、构建步骤或数据库迁移。

## 兼容与历史

接口新增字段与可选参数保持旧调用兼容；不重判历史、不改规则版本、不写旧证据。日常刷新优先重新加载页面，若须重载后台先确认无未完成任务，保留计划与数据。

## 验证

Store/API 检查跨页变化、筛选总数、部分排名边界和统计范围。浏览器覆盖折叠矫正、响应式、热力滚动／键盘浮层／筛选、更多菜单、状态与分组。隔离 Magpie 联调后检查日常原生展示。
