# 监测界面优化

状态：已实现；自动验证通过；日常原生展示已刷新；用户体验验收待确认。
来源：2026-11-16 UI 评审及用户「全部修正，并刷新 Magpie 展示」。扩展现行 MQ／FP 规格，冲突处以本规格为准。

## 目标与边界

保留两主 Tab、宿主主题、系统字体与原生前端。改善监测上下文、最新记录可达性、证据复核、设置密度和变化辨识度。不改变调度、判定、历史证据或数据库结构。

## 需求

| ID | 可观察行为 | 失败或边界场景 |
| --- | --- | --- |
| UI-001 | 模型、类型、当前类型测试按钮集中；完整 ID 与当前计划可读；清空进入更多菜单 | 正常连接提示仍隐藏；移除模型不允许测试；清空范围与原规则一致 |
| UI-002 | 通过／未通过／异常色跨图表、列表、详情一致；状态同时含文字或符号 | 无法判定与调用异常保留独立标签；明暗主题、焦点与减少动态效果可用 |
| UI-003 | 热力图首现及切换模型默认展示最新日期，轮询保留滚动；时段标签固定；悬停或聚焦显示各结果数量 | 提供日期／时段筛选入口，日期、时段与按钮等高且底边对齐，时段框不采用平台紧凑外观；聚合红优先于橙不变；空格与进行中有明确说明 |
| UI-004 | 窄窗口记录以两行呈现，时间、结果、耗时、来源和详情可直接访问 | 热力图内部可滚动；主页面无横向溢出 |
| UI-005 | 奶牛详情先有效结果／来源、自动判断、答案对比与完整回答，再折叠矫正及参数／日志 | 矫正仍保留原始证据，保存后保持矫正展开及反馈；原有固定弹层标题不变 |
| UI-006 | 指纹候选和概率靠近，标明参考库内概率；候选变化显示前后候选，与参考库更新区分 | 部分排名无概率；真实采样阶段来自已保存样本摘要，不伪造进度 |
| UI-007 | 设置按模型以紧凑独立计划行显示；指纹空间隔预先提示；自动保存反馈仅修改时显示，失败持续可重试 | 参考库可用状态、版本／时间和错误分行；暂停与下次计划一直可见 |
| UI-008 | 奶牛显示热力图对应 30 个服务日期的各结果次数；指纹显示最近 30×24 小时的轮数、完整／部分排名及候选变化次数 | 统计不随分页／时段／变化筛选变化；人工结果用于奶牛次数，不计算总体能力分数 |
| UI-009 | 指纹「仅看变化」筛选在服务端分页前应用，包含候选变化及参考库更新；相邻比较跨页保持正确 | 部分排名不触发候选变化；参考库更新可独立出现；清空仍针对全部终态 |
| UI-010 | 可折叠本页内连续相同候选、同参考库、同 SDK 的完整评分，默认逐条展示 | 变化边界及部分／异常／运行中不合并；分组标明本页和记录数，不跨日期、不跨页，分页仍按原始记录每页 20 条 |
| UI-011 | 历史与设置不以副标题、页脚或常驻操作教程重复控件和图例；列表仅在时段筛选生效时显示筛选范围 | 保留图例、表单与无障碍名称、请求用量、参考库内概率、错误和恢复入口 |
