# 模型共享检测设置

状态：已实现；自动验证与用户验收分别见 [验收](contracts/acceptance.md)。来源：2026-11-19 用户确认合并设置方案并要求修改。覆盖 FP-001、UI-007 的独立计划设计，以及 FP-003 的手动计划推进规则。

## 目标与边界

每模型一张卡片，勾选奶牛／指纹，间隔、推理强度、超时共享。保留 Bun、原生前端、SQLite v2 表结构与全部历史证据。

## 需求

| ID | 可观察行为 | 失败或边界场景 |
| --- | --- | --- |
| MS-001 | 每模型一份共享配置及测试项选择；新模型预选奶牛、30 分钟、300 秒、默认强度、自动关闭 | 零选择允许保存，但自动关闭且禁用运行；勾选不触发调用 |
| MS-002 | 一个定期开关及下次时间；定时执行所选项；立即检测所选项 | 同模型串行、全局最多两条模型任务；重复整组提交拒绝且不产生部分记录；单项失败不阻止另一项 |
| MS-003 | 两项超时各自计时，指纹覆盖整轮；入队固定配置快照 | 暂停及取消勾选只影响后续；移除取消未完成；休眠无积压补跑 |
| MS-004 | 共享配置和选择原子保存；手动所选项推进统一计划 | 历史页保留单类型手动测试，选中项推进统一计划，未选中项不改变计划；完成超长整组后统一推进过期计划 |
| MS-005 | 旧参数直接转换，不提供迁移选择界面；只有一项启用时使用该项参数，否则使用奶牛参数 | 启用项保留，全部暂停时预选奶牛；空缺间隔回退 30 分钟；保留最早启用项下次时间，不修改历史或已入队快照 |
| MS-006 | 一张模型卡片包含勾选、共享间隔、开关、立即检测、折叠高级设置及自动保存反馈 | 375–1440 宽度、明暗主题及键盘可操作；旧后台须提示重载 |
