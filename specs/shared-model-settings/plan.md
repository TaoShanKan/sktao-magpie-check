# 模型共享检测设置 · 实施方案

## 方案

Store 保留 v2 的模型／类型两行，事务保存同步的共享参数、shared 标记、selected 和 automaticEnabled。enabled 是定期开关与选择的投影；nextAt 在所选项中一致。Engine 暴露模型级读写、整组入队及统一推进计划，启动时自动转换旧配置。

新增 POST api/model-configs 与 POST api/run-selected；state 增加 modelConfigs，uiVersion=3，服务版本 0.5.0。已有 configs 和历史接口继续作为类型视图；已共享的模型拒绝旧式分项写入。

UI 每模型渲染一份表单，不提供迁移适配界面。

## 兼容与历史

不增加表、依赖或数据库迁移。直接转换所有旧配置：只有一项启用时优先采用该项，否则采用奶牛；空缺间隔回退 30 分钟。旧启用状态转换为测试项选择；零启用默认选择奶牛并暂停。记录及快照不改写，入队后改设置不改变任务。

## 验证

引擎／接口：原子保存与整组提交、统一 nextAt、失败继续、去重、旧参数来源优先级、快照与取消。浏览器：单卡配置、两项选择、自动保存失败重试、零选择、明暗与窄窗口。隔离 Magpie 联调继续使用模拟网关。
