# 指纹候选汇总图 · 实施方案

## 方案

Store 复用完整历史 CTE，增加 SDK 更新标记和 fingerprintOverview；服务增加只读 api/fingerprint-overview?model=&days=1|7|30，返回范围、总数、摘要点和明确截断信息。最多 10000 轮，无长回答／请求，UI 按候选 ID、状态与时间小区间聚合重叠点，组内保留单轮入口。

前端在独立 overview section 内渲染 HTML 轨道和按钮，真实时间定位，标签固定、时间网格与独立版本事件行。点组聚焦／悬停浮层，点击单点详情或组内记录列表。仅变更内容时重绘，防止轮询抢焦点。

## 兼容与历史

新增只读接口和 uiVersion=2，版本 0.4.0；旧后台须重载。无数据库迁移、重判或调度改变。
