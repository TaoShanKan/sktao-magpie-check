# 指纹候选汇总图

状态：已实现；自动验证通过；日常 Magpie 已刷新，用户体验待验收。
来源：2026-11-16 用户要求实施候选随时间分布图并查看 Magpie 效果。

## 目标与边界

在统计与逐条时间线之间显示候选随真实时间的分布，保留检测空档，不连接点、不推断持续模型身份。维持原生前端、SQLite v2 和现有判定。

| ID | 可观察行为 | 失败或边界场景 |
