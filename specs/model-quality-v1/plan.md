# 模型质量第一版 · 基线设计

此文件回填已实现方案；后续行为承诺以 [规格](spec.md) 为准。

## 模块与数据流

- Magpie 加载插件入口，受管服务处理共享与接管；启动页通过宿主 bridge 获取页面服务地址并导航。实际页面使用原生 HTML/CSS/JavaScript，运行时无需 npm 依赖或前端构建。
- 服务负责模型目录、配置、任务及历史接口。引擎统一排队、去重与并发控制；网关模块读取 `/v1/models`，发送非流式 Chat Completions。
- 测试定义将原题与判定规则分离。记录在排队时保存配置、题目和版本快照；回答完成后保存原始证据及自动结果。
- SQLite 独立保存配置、记录、人工日志和服务拥有者。界面请求只带短期页面服务令牌，网关密钥在服务端使用。
- 前端轮询状态，历史列表加载摘要，详情按需读取完整回答；人工结果由服务写入并重新汇总热力图。

源码入口、API 和数据结构见 [知识库](../../project-knowledge/INDEX.md)，避免在此维护另一份字段清单。

## 生命周期与兼容

- 进程恢复时保留终态记录，将遗留排队／执行中记录修复为中断；计划到期至多入队一次。共享服务的拥有者退出后，其他宿主尝试接管。
- 关闭计划、移除模型、清空历史遵循各自边界；清空只删已结束记录，不让未完成请求的回调恢复已删旧记录。
- 人工覆盖不写回自动结果。恢复只清除当前人工覆盖，追加日志。规则版本随快照保存；本版没有自动重判历史的入口。
- 后续测试可以新增独立定义；引擎和页面目前固定选择 `milk`，新增注册项本身不会自动启用新测试。

## 验证

以 [验收矩阵](contracts/acceptance.md) 关联判定、调度、持久化、浏览器流程和 Magpie 沙盒联调。真实模型及原生环境的结论独立记录，不能从模拟网关推断。

## 判定规则 v2 修复

原规则只识别 `average adult height`、`final answer` 等标记，分支一旦命中就不会尝试框选答案。句末 `Rounded to four significant figures:` 不在标记列表，可能导致前面的叙述或推导被当作最终结论，也可能在无框选时完全无法提取。

在相同的最终结论提取路径中加入 `Rounded to four/4 significant figures:`，仍选择最后标记并沿用数值、单位、否定和多候选校验。无需引入模型裁判、运行时依赖或数据库迁移；不以全文包含标准答案作为通过条件。只为已经确认的格式补充识别，其他表达仍可能需要人工确认。快照版本升至 `milk-final-v2`；历史处理见规格兼容性章节。
