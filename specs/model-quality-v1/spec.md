# 模型质量第一版

状态：已实现；自动验证与实际环境验收分别见 [验收记录](contracts/acceptance.md)。
来源：本项目用户确认的简化页面、两 Tab 调整、多模型独立配置及人工矫正需求；后续确认 Tab 背景透明、正常时隐藏连接提示。初始化日期：2026-11-13。

## 目标与边界

在 Magpie 内使用奶牛推理题观察指定模型的表现，定期保存结果，并允许用户复核自动判断。本文件记录首期只启用 `milk` 的基线；后续指纹能力、独立计划及新版 UI 由 [指纹规格](../fingerprint-monitoring/spec.md) 扩展。自动封锁和云端同步仍不在交付中。单题结果不证明模型身份。

## 需求

| ID | 可观察行为 | 失败或边界场景 |
| --- | --- | --- |
| MQ-001 | 侧边栏「模型质量」打开插件；内部仅「历史记录」「设置」两个 Tab，默认历史 | 通过页面服务进入真实界面，空记录有添加模型入口 |
| MQ-002 | 从 Magpie 目录添加多个完整供应商模型 ID，各自配置间隔、启停、推理强度、超时；有效修改自动保存 | 新模型默认暂停；推理强度只选模型支持值；保存失败可重试 |
| MQ-003 | 间隔默认 30 分钟，范围 1–43200；超时默认 300 秒，范围 10–3600；推理强度默认不指定 | 输入须为范围内整数；目录不可用时可刷新，不用伪造目录代替 |
| MQ-004 | 经网关发送原始奶牛题；使用 Chat Completions，由 Magpie 转换协议 | 不给模型提供标准答案或工具；不把截断、空回答及接口错误判成推理错误 |
| MQ-005 | 最终答案按四位有效数字与 46.24 英寸比较；支持常见 Markdown、LaTeX 包装及 `Rounded to four/4 significant figures:` 结论 | 采用最后明确的结论标记；明确错误结论仍未通过；中间正确值不直接使记录通过；歧义结论为无法判定 |
| MQ-006 | 调度在服务端运行；每模型一个未完成任务，全局最多两个并发，手动与定时共享限制 | 重复提交拒绝；无自动重试；休眠或重启不积压补跑；手动测试重算下次时间 |
| MQ-007 | 关闭自动测试保留当前请求，修改配置只影响后续请求；移除模型停止计划并取消未完成测试 | 已移除模型的历史仍可选择查看；服务重启修复遗留运行中记录 |
| MQ-008 | 历史页选择单个模型，展示最近 30 天 × 4 个六小时时段的热力图；列表按时间倒序、每页 20 条 | 时间按服务时区；点格子筛选时段，可取消；列表只加载摘要 |
| MQ-009 | 单条详情提供完整回答、请求快照、版本、时间耗时、调用状态、自动判断和提取答案 | 模型回答作为文本呈现；未完成记录可查看但暂不可人工矫正 |
| MQ-010 | 人工可改为通过、未通过或无法判定，备注选填；可恢复自动判断，每次操作留下日志 | 原始回答、自动判断与调用状态保留；有效结果优先采用人工判断并更新列表和热力图 |
| MQ-011 | 热力格绿=全部通过、红=存在未通过、橙=存在异常或无法判定、灰=无已结束记录 | 红优先于橙；未完成任务单独计数并显示虚线；人工矫正可覆盖异常记录的有效结果 |
| MQ-012 | 确认后清空当前模型全部已结束记录及日志，保留配置；日期筛选不限制删除范围 | 未完成任务保留，其完成结果仍出现；清空与移除模型是不同操作 |
| MQ-013 | Tab 背景透明，跟随页面；适配宿主主题。正常连接不显示状态文字，连接失败才提示并提供重试 | 服务重启导致页面令牌失效时提示重新加载；窄窗口可操作 |
| MQ-014 | 本地持久化配置、回答、快照与矫正日志；同数据目录只由一个服务调度 | 网关密钥留在服务端，页面使用独立服务令牌；临时隔离验证不修改日常配置 |
| MQ-015 | 非回环网关必须使用 HTTPS 且配置密钥；`localhost`、`127.0.0.1`、`[::1]` 可继续使用 HTTP | 明文远程配置在启动时拒绝，不降级发送；需更新网关配置再重启，不迁移或重写历史 |

## 兼容性与未决项

当前基线从无业务数据的 Hello Word 页面升级而来。数据库结构、判定规则或请求参数的后续变化须说明旧记录如何处理，不能通过修改设置悄悄重写历史证据。

2026-11-13 判定规则更新为 `milk-final-v2`，补充句末四位有效数字结论识别。题目仍为 `milk-original-v1`，标准答案及数据库结构不变。服务重载后新入队记录使用新规则；旧记录保留其规则版本、自动判断及人工日志，不自动重判。离线回放仅用于验证，不写入历史。

无阻塞当前实现的产品未决问题。原生 WebView、远程部署和真实供应商调用的验收状态单独列在验收记录中。
