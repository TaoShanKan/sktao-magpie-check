# 模型质量 · Magpie 插件

使用奶牛推理题定时测试多个模型，查看热力图和逐条回答，并支持人工矫正。数据保存在本机。支持数字指纹检测与候选变化时间线；不提供自动封锁或云端同步。

## 安装到 Magpie

需要安装支持页面服务的 [Magpie](https://usemagpie.ai/docs/zh/plugins)。已在 macOS 的 Magpie `0.1.4504` Web 宿主通过联调；这不是最低版本要求。

克隆本仓库并在 Magpie 中添加本地目录：

```sh
git clone https://github.com/TaoShanKan/sktao-magpie-check.git
cd sktao-magpie-check
magpie plugin add "$(pwd)"
```

也可以下载并解压仓库，在 Magpie「插件 → 添加插件」中选择包含 `package.json` 的目录。侧边栏入口显示为 **模型质量**。无需构建或安装 npm 依赖，由 Magpie 的 Bun 插件宿主启动本地服务。更新本地文件后，请停用再启用插件。

## 使用

1. 进入「设置」，点击「添加模型」，从 Magpie 文本模型目录选择模型。
2. 每个模型勾选奶牛／指纹检测项目，共用间隔和定期检测开关；高级设置共用推理强度与每项检测超时。修改并离开输入框后自动保存。
3. 新增模型默认预选奶牛且暂停。可勾选指纹后点击「立即检测所选项」，再按需打开定期检测。每次测试都会调用所选模型并产生正常请求用量。
4. 「历史记录」中选择模型，查看最近 30 天热力图。每格代表一天中的 6 小时时段；点击格子筛选下方列表。
5. 点击「详情」先查看结果、答案对比与完整回答，再展开「人工矫正」；可人工修改为通过、未通过或无法判定，备注选填，也可恢复自动判断。修改不会改变原始证据，日志会保留。
6. 「更多 → 清空历史」在确认后删除当前模型、当前检测类型全部已结束记录及矫正日志，不受当前日期筛选限制。配置保留；正在运行的测试完成后仍会出现。移除模型配置会取消其任务、保留历史。

正常连接时不显示状态文字；连接失败时显示错误和重试入口。

热力图按最终有效结果汇总：绿=全部通过，红=存在未通过，橙=存在调用异常或无法判定，灰=无已完成记录。红色优先于橙色；鼠标悬停可查看数量，进行中的格子带虚线边框。时间使用服务所在系统时区，可通过选项覆盖。

## 运行行为

- 默认间隔 30 分钟、超时 300 秒、推理强度默认。间隔范围 1–43200 分钟，超时范围 10–3600 秒。
- 同模型同检测类型最多一个未完成测试；同一模型的两种检测串行，全局最多两个同时执行。无自动重试；所选项共用下次计划，手动执行所选项会统一推进。历史页可单独测试当前类型：已勾选项推进共享计划，未勾选项不影响计划。
- 页面关闭或切换 Tab 不停止定时测试；Magpie 插件宿主与本地服务需要持续运行。休眠或停机期间不执行，恢复后每模型最多补执行一次。
- 关闭定期检测或取消勾选不会取消已入队任务；修改配置只影响后续测试。移除模型则取消其未完成任务。
- 标准答案是 46.24 英寸；支持常见 Markdown、LaTeX 单位和框选格式，按四位有效数字比较。无法可靠提取最终结论时记为无法判定；超时、空回答、截断和接口失败记为调用异常。人工判断优先，但原始调用状态保持不变。
- 这道题只反映本题表现，不验证模型身份。

## 连接与数据

插件默认监听 `127.0.0.1:4397`，网关地址优先从 `MAGPIE_ADDR` 读取，其次从 Magpie 的 `settings.json` 读取端口，默认 `127.0.0.1:3425`。

可在 Magpie 插件选项中设置：

```json
{
  "port": 4397,
  "gateway": "http://127.0.0.1:3425",
  "dataDir": "/your/private/path/sktao-check",
  "timeZone": "Asia/Shanghai"
}
```

`gateway` 可省略，支持以 `/v1` 结尾的地址。`localhost`、`127.0.0.1` 和 `[::1]` 可使用 HTTP；其他地址必须使用 HTTPS 并配置密钥。原来使用远程 HTTP 的配置需改为 HTTPS，再重启插件。

通过插件选项 `apiKey` 或启动 Magpie 时的 `SKTAO_CHECK_API_KEY` 配置密钥，密钥不会传给浏览器。不要提交密钥、Magpie 配置或运行数据目录。

也支持环境变量 `SKTAO_CHECK_PORT`、`SKTAO_CHECK_GATEWAY`、`SKTAO_CHECK_DATA_DIR`、`SKTAO_CHECK_TIME_ZONE`。默认数据库位于 `~/.config/magpie/sktao-check/quality.sqlite`（尊重 `XDG_CONFIG_HOME`）。配置、原始回答和人工日志都在该数据库中。备份前先停止插件，再复制数据目录；没有自动过期删除。

端口被其他应用占用时会提示错误，请更换 `port`。同一端口且配置一致的多个插件宿主共享服务，原宿主退出后接管；不同端口不允许对同一数据库重复调度。远程 Magpie 页面依赖宿主提供的插件页面服务代理。

## 开发与验证

本机独立运行需要 Bun 1.2.20 或更新版本：

```sh
bun start
```

打开终端输出的地址。直接打开 `page/index.html` 无法连接 bridge；它是 Magpie 的启动入口，实际界面由本地服务提供。

```sh
bun install --frozen-lockfile
bun test
bun run test:browser
bun run test:magpie
```

浏览器测试使用 Playwright 和模拟网关，不调用真实模型。首次运行可执行 `bunx playwright install chromium`；已有 Chromium 时可设置 `PLAYWRIGHT_EXECUTABLE_PATH`。测试截图保存到 `docs/screenshots/`，截图中的模型及历史均为模拟数据。

`test:magpie` 额外需要本机 `magpie` CLI，以独立的临时 HOME、配置和数据库完成安装及内嵌页面测试，退出后清理。该测试会复制已有 Bun 缓存以减少下载，不修改日常 Magpie 配置。

主要模块：`src/tests/`（题目与判定）、`src/engine.js`（调度）、`src/store.js`（SQLite）、`src/server.js`（服务接口）、`ui/`（两个 Tab 及详情抽屉）。添加测试类型时扩展独立测试定义，当前支持 `milk` 与 `fingerprint`。

参考：[Magpie 插件文档](https://usemagpie.ai/docs/zh/plugins)、[LaTeX 误判问题 #3](https://github.com/mu-zi-lee/magpie-intelligence-check/issues/3)。题目及第三方说明见 `THIRD_PARTY_NOTICES.md`。

## 指纹监测

历史页切换到「模型指纹」，按日期查看最可能模型与概率；候选变化、参考库更新分别标记。点击记录查看 Top 3、完整排名、题目／回答和实际路由证据。概率仅在参考库候选中分配，不证明身份；样本不足时可保留排名，概率显示 —，不提供人工通过／未通过矫正。

每轮最多三条数字采样请求，逐条执行并产生正常用量。在模型卡片中勾选指纹即可使用共享配置，勾选不会立即调用。默认间隔 30 分钟，每项超时 300 秒；奶牛为单次推理超时，指纹为整轮超时，分别计时。两项全选时每轮最多 4 条请求。

参考库首次检测自动下载；有缓存后每 24 小时自动尝试更新，也可在设置中手动更新。更新失败继续使用已有快照并提示，运行中的轮次固定原快照。默认来源为 https://lm.ikale.io/data/ 和 https://cdn.jsdmirror.com/npm/lmfpd-data@latest/ ，下载不携带模型凭证或回答。可通过选项 `bankSource` 或 `SKTAO_CHECK_BANK_SOURCE` 指定本地目录或 HTTP(S) 数据源。

数据库自动从版本 1 迁移到 2，保留旧奶牛配置、记录和人工日志。升级后应关闭再打开插件，使旧服务退出。参考缓存和更新状态位于数据目录的 reference.bin、reference-state.json；旧记录不随参考库更新重新评分。

## 界面与历史筛选（0.3.0）

历史页在模型旁选择奶牛／指纹，按钮明确当前测试类型；下方显示完整模型 ID、当前计划和下次时间。清空历史移至「更多」菜单，删除范围仍为当前模型、当前类型的全部终态。

奶牛热力图首次显示最近日期，手动横向滚动后轮询保留位置。悬停或键盘聚焦格子查看各结果数量，也可使用日期和时段表单筛选。窄窗口记录改为两行，详情无需横向滚动。通过标签统一为绿色，未通过红色、调用异常琥珀色；文字与符号共同区分状态。

统计显示明确范围：奶牛汇总热力图的 30 个服务日期，采用人工矫正后的有效结果；指纹汇总最近 30×24 小时的轮数、完整／部分排名、候选变化和参考库更新。统计不随分页或局部筛选变化，不代表综合能力分数。

指纹「仅看变化」包含候选变化和参考库更新，先筛选再分页。「合并本页相同候选」可折叠本页同日期、同候选、同快照和同 SDK 的连续完整记录；变化、异常和部分排名不合并。每页仍为 20 条原始记录，展开可查看各条概率与详情。执行阶段来自真实采样摘要。

## 指纹候选汇总图（0.4.0）

「模型指纹」中，统计下方显示候选随时间分布图，默认最近 7 天，可切换 24 小时／30 天。横轴为真实时间、每个候选独立一行；实心圆表示完整评分、空心菱形表示部分排名，异常／无候选和执行中分别列行。空白不表示持续使用同一模型，点之间不连接。

悬停或键盘聚焦点可看摘要，点击单点打开详情；数字点代表相近时间多轮记录，点击展开逐轮列表。版本事件行分别标记参考库与 SDK 更新。图表独立查询范围，不受下方分页及「仅看变化」限制；超出 10000 轮时明确提示省略数量，缩短范围可查看。窄窗口可横向滚动，候选名称固定。

## 共享检测设置（0.5.0）

每模型仅显示一份配置。测试项选择与定期开关分开：暂停时保留选择，取消全部选择时自动关闭定期检测并禁用立即检测。每轮按奶牛、指纹顺序串行执行，单项失败不阻止另一项，历史仍按类型保存。超长整组完成后推进已经过期的计划，不积压补跑。

升级时旧参数直接转换，不增加迁移选择界面。只有一项开启定期检测时采用该项参数；两项都开启或都暂停时采用奶牛参数。合并保留已启用的测试项，全部暂停时预选奶牛且继续暂停，不修改历史或已经入队的快照。

SQLite 仍为 v2，无新增运行时依赖。0.5.1 修复多窗口设置覆盖、历史切换与图表刷新。更新时请等进行中的检测结束，在 Magpie 中关闭再开启「模型质量」，然后重新加载页面；新页面会提示不兼容的旧后台。
