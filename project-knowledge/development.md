# 开发与验证

命令入口以 [package.json](../package.json) 为准。运行和连接选项见 [README](../README.md)，验收证据见 [首期验收](../specs/model-quality-v1/contracts/acceptance.md)。

## 验证选择

| 改动 | 首选检查 | 需要扩大验证的情况 |
| --- | --- | --- |
| 题目提取、规范化或判定 | `bun test tests/milk.test.js` | 与调用完成条件相关时加 server 测试 |
| 队列、计划、取消或超时 | `bun test tests/engine.test.js` | 生命周期或拥有者变化时加 server、Magpie 联调 |
| SQLite、覆盖结果或历史查询 | `bun test tests/store.test.js tests/server.test.js` | 页面筛选、详情或矫正变化时加浏览器流程 |
| API、网关与访问边界 | `bun test tests/server.test.js` | 影响页面代理时加 Magpie 联调 |
| 前端交互、主题及错误状态 | `bun run test:browser` | 涉及 bridge、宿主背景或代理时加 Magpie 联调 |
| 插件清单、启动页、服务共享 | `bun run test:magpie` | 真实原生／远程部署仍需独立验收 |
| 文档 | 本地链接、来源和状态核对 | 仅在重新确认验证声明时运行相关检查 |

服务端全量检查是 `bun test`。当前没有仓库 lint、类型检查或前端 build 脚本；文档中不把未配置的命令当作验证完成条件。

GitHub Actions 在 Ubuntu 24.04 上用 Bun 1.2.20 执行 `bun test`。它不需要安装浏览器或 npm 依赖。Chromium 与 Magpie 联调仍是独立检查。首次公开前按 [发布清单](release.md) 审查拟提交文件。

## 测试数据与隔离

- [helpers](../tests/helpers.js) 启动模拟 HTTP 网关及临时数据库。`mock/logic-*` 是测试对象，不能当成用户实际可选模型。
- [浏览器脚本](../scripts/browser-check.js) 使用 Chromium，验证两个 Tab、独立参数、矫正与恢复、热力格筛选、分页、错误恢复、主题和窄窗口；退出后清理测试服务。
- [Magpie 脚本](../scripts/magpie-check.js) 使用本机 CLI、独立临时 HOME／配置／数据库及模拟网关；可复制已有 Bun 运行时缓存，退出后清理临时目录。
- 两个界面脚本都会生成模拟数据截图。截图是执行产物，可能落后于之后的文案修正；不能单凭它证明当前所有行为。
- 浏览器首次使用需要可用的 Playwright Chromium，或通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定已有浏览器。缺少运行时或 CLI 时报告环境限制，不能记成通过。

## 常见定位

| 现象 | 优先检查 |
| --- | --- |
| 侧边栏入口缺失 | `package.json` 的 `magpie.page`、插件是否启用、修改后是否重载 |
| 启动页无法进入界面 | `page/boot.js` 的 bridge、页面服务地址和端口；远程宿主是否提供服务代理 |
| 页面有了但接口不可用 | 浏览器网络请求、相对 API 地址、Origin、CSP、短期令牌；重启后重新加载页面 |
| 模型目录加载失败 | 服务端网关地址和认证、`GET /v1/models`；正常页面连接不证明网关可用 |
| 计划没有运行 | 模型是否启用、`nextAt`、未完成任务、宿主是否运行以及服务拥有者 |
| 判断与预期不同 | 请求是否完整结束、原始回答、提取值、规则版本、是否已有人工覆盖 |
| 清空后又出现记录 | 是否为清空时尚未结束的任务；这是当前约定，不是恢复旧历史 |
| Tab 出现白块 | `.tabs button` 是否仍显式透明；页面背景可能来自宿主 `--magpie-bg` |
| 运行中一直没有结果 | 超时配置、请求取消、服务是否异常退出；启动时应修复遗留任务 |

判定排查应保留结论边界：`normalizeAnswer` 会移除换行，`grade` 选择最后匹配的结论标记。一旦命中标记便不会回退到框选提取；新增表达应加入结论识别并复用安全校验，避免全文搜索正确数值造成误通过。`milk-final-v2` 补充四位有效数字结论。验证历史样本时以只读方式打开运行库，在内存调用 `milk.grade`，不使用会建表／修复状态的 `Store` 构造器，不更新旧自动判断。

## 证据边界

记录实际执行的命令、日期、环境及结果。当前测试证据覆盖模拟网关、SQLite、Chromium 和 Magpie web；不把它扩大为真实模型、原生 macOS WebView 或远程部署已验收。

真实模型调用会产生用量。需要验证时使用用户授权的目标和次数，记录真实结果并与模拟验证分开；运行数据库、密钥及用户回答保持在仓库外。

## 指纹验证

`bun test tests/fingerprint.test.js` 覆盖本地 SDK 兼容入口、采样、概率传播、路由、迁移、计划、参考库原子更新及跨页变化。所有排名夹具为示例数据；空参考库夹具不验证生产评分。浏览器脚本同时覆盖指纹时间线与 375/768/1024/1440 布局，截图 fingerprint-light.png 和 fingerprint-dark.png。

2026-11-13 实机升级排查：服务健康仍为 0.1.0、数据库 v1，但 UI 为新版时会出现 undefined、更新假等待和旧奶牛记录混入指纹。修复增加协议校验和旧后台提示；重载后原生 WebView 确认两套设置、公开参考库下载成功、奶牛 20 条保留且指纹 0 条。浏览器回归包括 v1 响应及恢复重绘。

## 0.3.0 界面验证

新增 Store/API 用例检查变化筛选先于分页、统计覆盖完整区间、部分排名及 SDK／快照边界。浏览器覆盖热力图首次定位最近日期与轮询保留位置、聚焦统计浮层、日期／时段筛选、窄屏详情直接访问、证据先于矫正和本页候选折叠。Popover 的 toggle 为异步事件：测试菜单键盘前应等待选中项获得焦点。浮层焦点引起的自动滚动需先稳定布局再显示，不能因轮询无条件重建热力格或分组正文。

日常刷新先只读确认无 queued/running，避免中断已授权的自动任务；使用插件 off/on 重载后台，再激活原生窗口后重新加载。健康版本通过和原生内容可见分别记录，不能以 CLI 成功代替页面验证。

## 0.5.0 共享配置验证

`bun test tests/shared-settings.test.js` 覆盖共享选择、原子保存／整组入队回滚、统一计划、超长任务无补跑、失败继续、旧参数直接转换及来源优先级、历史快照和 API 持久化。浏览器原有独立参数断言改为共享参数，并覆盖零选择、保存重试、两项一起运行和键盘勾选；隔离 Magpie 脚本使用共享卡片入口。
